# X-Synth 工作区交互与能力边界

产品版本为 0.1.0。业务界面使用 X-Synth 品牌；后端引擎、模型和模板来源在环境清单与
技术详情中保留。浏览器请求只进入产品 API，不绕过任务编排、身份与采购证据门禁。

## 化学工作流程约束

目标用户是药物化学与有机合成研究人员。所有页面按化合物、反应、原料与路线组织，
不要求用户理解图节点、JSON schema、库存哈希或搜索算法才能进行常规操作。
结构图与反应物到产物的关系是主要信息；SMILES、内部标识和运行详情为辅助信息。
搜索算法参数集中在高级设置；界面标题或默认模型用途标签不能改变实际参数、模型或质量门槛。

| 对象 | 常规输入与操作 | 文件边界 |
|---|---|---|
| 目标、原料、中间体 | 绘图、粘贴 SMILES、结构预览后应用 | MOL V2000/V3000、SDF、SMILES 文本文件 |
| 多化合物文件 | 逐页预览结构/名称/分子式/MW；显式选择一条 | 不默认取第一条，不自动批量提交推理任务 |
| 单个反应 | 反应物 → 所选产物；试剂/溶剂记录单独展示 | 单反应 MDL RXN 导入/导出；不解释为多步合成路线 |
| 完整路线 | 图形与正向合成步骤；原料查询、步骤详情、编辑副本 | X-Synth 路线 JSON；完整图 PNG；分子可单独导出 MOL/SDF/SMILES |
| 人工设计步骤 | 选择已有产物，逐条录入反应物并整体加入连接 | 保存为草稿，不添加模型分数、实验收率或商业闭合声明 |

化学文件通过 `/api/v1/structure/import`、`export`、`reaction-import`、`reaction-export` 共用产品身份边界
与真实 RDKit 解析，不引入另一套名字解析、绘图推理或专用目标脚本。文件按 UTF-8 文本
处理，单次 2 MiB/100 条记录的读取保护拒绝超限而不截断内容；未写入任务历史或供应商数据库。
结构字段沿用现有原子数与 SMILES 长度上限。所有记录先完整验证，任何无效记录都会拒绝整个导入。
保留盐/离子组分、确定的立体化学、同位素和双键构型；未定义 R 基、查询结构、相对/混合
立体化学组与不支持的聚合物不得被转换成貌似确定的目标。分子式/MW 由当前结构计算，
多组分时为完整记录的结果，不自动只取主成分。导出执行结构身份回读检查，不假称保留原排版、
三维坐标、所有 SDF 属性、原图文本或 ChemDraw 专有注释。

RXN 的多个产物需显式选定一个评分产物；试剂/溶剂记录不会并入 FF 的反应物输入，
也不作为条件预测。绘图或文件记录尚未确认时不能执行创建、加入步骤或评分；晚到的文件响应
不能覆盖新的结构、反应或文档。FF 是模型评分而非实验成功率。CAS 与名称只作为已有记录的身份信息，
未接入可靠名称解析服务时不能用 CAS/名称猜结构。CDX/CDXML、PDF 结构识别、ELN、
收率预测不能仅因参考软件有按钮而启用；已部署的条件模型有独立就绪探针与结构化结果。

正向步骤按真实前体依赖拓扑排序，所有分支在其产物后续步骤前出现。图标签与列表序号一致，
原始模型步骤索引、验证证据、模板来源和结果文件不被改写。循环或重复产物不能获得伪造的
正向顺序。界面中的“反应物”用于一个具体步骤，“起始原料”只用于整条路线的叶子；
没有采购记录的起始原料不自动标为商购。

文件互操作采用现有 [RDKit 文件解析接口](https://www.rdkit.org/docs/source/rdkit.Chem.rdmolfiles.html)
与 [Ketcher 分子绘图器](https://github.com/epam/ketcher) 的确定结构表达；不把最新版编辑器的
格式说明误当成本项目随带 2.13 版本的能力。内嵌和弹窗绘图板共享一个版本限定的响应式
适配器，移除原画板 640px 最小宽度并调整视图中心/缩放，不改第三方 bundle，也不修改
分子坐标来补偿窗口尺寸。验收检查实际结构边界，不以空白画布或页面无滚动条代替。

## 导航组织

侧栏提供路线设计、任务与路线两个工作入口，以及原料检索、反应与条件、结构工具、
工艺核算和实验优化；环境部署位于左下角。高频操作可直接到达，小功能按化学工作对象
合并，不把评分、绘图、库存或任务生命周期合并成同一种计算。

| 主入口 | 内部操作 | 保留边界 |
|---|---|---|
| 路线设计 | 完整路线、单步逆合成、打开路线文档 | 一步分析不再占第二个侧栏入口；所有模式继续使用同一绘图板与执行契约 |
| 任务与路线 | 路线任务、研究记录、保存的路线、编辑副本 | 原始计算与可编辑草稿独立存储；研究计算不冒充完整路线任务 |
| 原料检索 | 结构输入、精确查询、供应商目录 | 单功能工作区不叠加重复标签；采购快照不等于实时库存 |
| 反应与条件 | 条件推荐、产物预测、杂质候选、FF、模板检索 | NNv1、Graph2SMILES 与杂质分析使用产品同步边界；不存在旧异步模型备用链路；FF 是独立模型评分 |
| 结构工具 | SA/SPS/Bertz/描述符、SCScore、结构绘制 | 按真实结构计算，保留盐与同位素，不冒充实验可合成性证明 |
| 工艺核算 | 物料质量、分离产物、纯度、计量依据、PMI | 录入数据核算；缺项不补零，质量差额不是实测废物，不能替代放大验证 |
| 实验优化 | CSV、显式实测行、因子水平、响应、下一批条件 | BayBE / BoTorch；不读取未选响应训练，不给建议填实验收率 |
| 环境部署 | 引擎、部署配置、运行监测；已授权的用户/禁用规则管理 | 不提供浏览器执行系统命令；没有重复的本地工作区入口 |

每个研究工作区只显示自己的工具，不在原料查询上叠加反应/结构工具标签。反应与条件
直接切换其高频操作，结构工具直接切换评估、SCScore 与绘图。单功能工作区不叠加单项导航。
原生溶解度工作台保持一个二级入口。工具列表复用产品就绪快照；实验优化使用独立缓存探针，
不能阻塞路线搜索就绪，也不会因模型正在计算而撤掉已验证的入口。
点击当前工作区保留所选页面与结构/反应/模板预填，不把它重置到默认工具。
任务详情与路线编辑保持完整画布，不叠加集合页标签。
旧 `/results`、`/documents`、`/editor`、`/buyables`、`/feasibility`、`/molcom`、
`/template`、`/drawing` 等链接和节点分析预填保持有效，不引入重复路由或推理链路。
旧 `/forward?tab=impurity` 转入已接入的杂质工作区；未接入的选择性及非法模型标签转到
真实环境清单，不静默执行条件模型。未使用的旧杂质、区域和位点结果组件已移除，原生后端源码仍保留。

## 点击链路

| 页面 | 点击路径 | 数据与状态约束 |
|---|---|---|
| 新建任务 | 绘图/结构文件 → 确认化合物 → 完整路线搜索/单步逆合成 | 显式提交才执行推理；已支持的重新搜索参数完整回放 |
| 任务历史 | 卡片/列表 → 参数 → 预览 → 详情/编辑副本 | 原始路线顺序与任务标识不因排序而改变 |
| 任务详情 | 路线 → 图形/步骤/概览 → 节点详情 | 状态和路线文件独立加载；文件失败不能隐藏恢复与取消 |
| 分子节点 | 节点 → 采购记录 → 完整原料检索/供应商目录 | 精确结构匹配；显示查询快照并比较原任务快照；不伪造 CAS、报价或包装 |
| 分子节点 | 节点 → 一步分析/结构复杂度 | 只预填所选结构，不自动推理，不修改原始路线 |
| 反应节点 | 节点 → 反应结构 → 可行性计算 | 反应物与产物来自实际图连接；模型响应失败不是无候选 |
| 反应节点 | 来源模板 → 模板详情 → 返回检索 | 来源与 ID 共同定位；训练序号与内部反应引用不能猜成模板 ID |
| 模板详情 | SMARTS/限制/参考记录 → 已明确的公开链接 | DOI、专利与 HTTP 链接校验；数字内部引用只显示原值 |
| 原料检索 | 预填/手输 → 验证 → 结构与记录一起提交显示 | 新查询失败或晚返回时不能将旧供应商记录挂在新结构上 |
| 路线文档 | 预览节点 → 编辑 → 应用 → 保存/导出 | 验证完成前固定节点与输入；切换节点后旧结果不能写入新节点 |
| 路线文档 | 未保存画布 → 打开路线文档 JSON | 用户确认前不创建导入文档、不清除修改、不跳转 |
| 路线文档 | 保存状态 → 科学状态 → 原始任务 | 保存成功与来源副本/草稿分开；修改化学结构使原计算声明失效 |
| 原生历史 | 历史记录 → 共享预览/详情 → 编辑副本 | 原生 UDS 用同一解码器投影；原文件保留，不重新认证商业闭合 |
| 环境部署 | 当前引擎 → 原生能力 → 未接入软件 → 数据依赖 | 只展示真实接入状态，未启用模块不是功能按钮 |
| 反应与条件 | 反应结构 → 右侧参数 → 显式提交 → 候选 → 研究记录 | 输入变化使旧响应失效；两种模型评分不混作实验验证 |
| 杂质候选 | 反应物、已知主产物与试剂/溶剂 → 确认输入 → 五模式分析 → 结构与来源 → 研究记录 | 原子映射检查必须执行；已知产物是用户参照，不伪造其模型分数；不推断杂质含量 |
| 结构评估 | 化合物 → 计算 → 组分指标 → 方法来源 → 研究记录 | 完整结构身份与各组分分开；Na 等无机组分不造 SA 分数 |
| 工艺核算 | 产品/投料 → 质量单位/边界 → 计算 → 物料与 PMI → 研究记录 | 分离总质量、质量纯度和录入收率分别保留；不自动补全未知项 |
| 实验优化 | 真实 CSV → 选择记录 → 因子/响应 → 确认候选空间 → 推荐/导出 | 原始表 SHA256、所选行、条件空间和模型版本绑定；建议 CSV 的实测响应保持为空 |

研究记录由服务端在实际执行时写入 `analyses.sqlite`，不会接受浏览器伪造的预测作为模型结果。
成功、失败和中断分别记录；进程启动身份用于恢复判定，PID 复用不被当成仍在运行。
记录详情与原工作区共享结果组件。型号、原始输入与结果不可修改，不会在刷新时自动重新推理。

预览与编辑共享 Vue Flow、Dagre、RDKit 与 Ketcher。节点分析共享同一 inspector；
采购弹窗与完整原料检索共享同一结构/快照响应校验。没有并存的旧 network 编辑器、
独立状态页或每结构专用推理脚本。
绘图写入队列以实际导入成功/失败事件为完成边界；提交前等待最新写入完成。
关闭页面会取消等待并释放监听器，超时或解析失败不得以输入文本替代画板结果。
取消或超时后不复用尚有后台写入的画板实例；重开弹窗创建独立实例。

## 智化交互对照

对照依据是 2026-10-04 可观察的 ChemAIRS 3.9.2 页面与官方公开产品说明，
不是对其私有源代码、模型权重、搜索算法或商业数据库的逆向结论。

| 智化可观察层次 | X-Synth 对应 | 尚无能力的边界 |
|---|---|---|
| 绘图板、搜索/手动/导入、参数与任务列表 | 结构工作台、原始参数回放、历史、预览 | Marvin 专有能力不冒充 Ketcher 能力 |
| 路线选择、查看、编辑、导出 | 图形/正向合成步骤/概览、编辑副本、JSON/全图 PNG；MOL/SDF 分子文件、RXN 反应输入 | CDX、BIOVIA Draw 与专有文件兼容尚未实现 |
| 分子节点价格、CAS、服务来源、包装、货期、购买链接 | 精确目录记录、原任务快照比较与采购链接 | 无真实数据时不填包装、纯度、人民币报价或综合成本 |
| 反应节点条件、参考反应、文献、相似度 | 实际反应、模型分数、模板/参考记录钻取 | 没有独立正向/条件模型与文献资料时不声称具备这些能力 |
| 文献/预测路线、供应商、价格、条件筛选与分组 | 已验证路线的来源/闭合/评分/步数筛选；家族选择在产品路线池执行 | 不把训练模板当目标的文献路线，不复制没有数据依据的过滤指标 |
| 精确/相似分子路线映射与可替换原料 | 精确原料证据与节点一步分析 | 没有相似路线资料或原料替换验证引擎，不制造替换结论 |
| 工艺、正向、可合成性、杂质、贝叶斯模块 | 工艺物料核算、真实产物预测、RDKit 评估、杂质候选、BayBE 实验优化 | 参考站受限子页面不推断其内部实现；批次核算不是工业放大预测，结构描述符不是路线成功证明 |

访问范围内已检查路线列表及供应商/反应条件/其它筛选、单条路线预览、
分子采购详情、展开参考条件、导出菜单、首页逆合成参数及条件工作台。
登录后已检查任务列表的逆合成/条件分区、名称/状态筛选、分组入口、批量选择与运行中结果提示。
未执行远程预测、上传、分组变更或删除；正向合成仍显示授权联系页面，因此其参数与结果层不能声称已体验。
商业参考软件的供应商目录、实时报价、文献与 ELN 数据是独立数据依赖，不能通过
复制 UI 获得。厂商公开说明可参考
[ChemAIRS 产品页](https://www.chemiscal.com/chemairs.html) 与
[交互更新说明](https://www.chemiscal.com/detail/143.html)；厂商的准确率声明不是本产品的验收数据。

## 验证与性能

只运行当前 diff 映射到的 Python/前端测试、构建和相关安全检查，不回退到全局套件。
模板导航契约测试使用真实 SQLite/FastAPI 响应与独立接口测试记录，公开 SMARTS 示例来自
[RDKit 文档](https://www.rdkit.org/docs/RDKit_Book.html#reaction-smarts)。测试中的计数、
ID 与分页参考记录仅是接口输入，不是预测结果、商业目录或实验文献。
它们不进入产品运行目录，也不替代本机真实模板库、库存和模型验收。CI 只在选择到这些测试时安装
产品 API 的哈希锁定依赖。`ci_scope` 传递所用 Python 解释器，
直接运行这些 npm 测试时可显式设置 `X_SYNTH_TEST_PYTHON`。

布局验收使用实际 Chrome/Playwright；API、库存、模板与所触及的模型执行路径需真实验证。
就绪缓存、模板摘要缓存与资源预算维持唯一权威，不通过降低科学门槛满足速度指标。
证据、截图、私人历史、模型与商业数据均保存在源码之外。
