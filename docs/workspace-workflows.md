# X-Synth 工作区交互与能力边界

产品版本从 `VERSION` 读取，按合并 PR 计数自动递增。业务界面使用 X-Synth 品牌；后端引擎、模型和模板来源在环境清单与
技术详情中保留。浏览器请求只进入产品 API，不绕过任务编排、身份与采购证据门禁。

## 界面语言

默认使用英语，语言菜单提供 English 与简体中文，并记住用户的明确选择。语言资源、
可用语言清单和原生控件的语言映射集中维护，新增语言需补齐所有资源与验证，不采用
只在两个值之间切换的专用分支。Vue I18n 是唯一的响应式语言状态；Vuetify 控件由
应用根节点的同一状态映射，不维护第二个语言设置。

只对程序控制的界面文案和显示日期执行本地化。完整句子使用命名参数，原始中文
文案作为消息标识；英文资源缺项、重复冲突、语法或参数不一致由关联检查拒绝。
不在 DOM 上替换文字，也不转换用户姓名、路线名称、CSV 字节与列名、SMILES / RXN、
CAS、目录号、型号、路径、许可或原始文献 / 实验原文。已知的程序生成科学提示可
忠实翻译显示，但不重写保存的结果；未知来源文本保留原样。

切换不刷新页面，不新建任务或改变接口参数，也不重挂载画板、清除选择、输入或
已保存记录。文档语言及日期展示随选择更新，结构、盐组分、立体化学、数值与单位
不因语言变化而改变。偏好只读写专用的非敏感 `x-synth.locale` 键；失效或未设置时
回到英语，存储不可用仍允许当前页使用所选语言。既有中文断言通过测试中显式选择
中文执行，不能据此把生产默认语言声明为中文。

## 工作区导航与恢复

二级模块导航只滚动自身的横向区域，使直接进入、切换语言、回退或尺寸变化后的
当前模块可见，不滚动正文或抢走阅读焦点。后台就绪状态更新不重置用户主动浏览
其他标签的位置。移动端导航抽屉覆盖整个视口，打开时背景页头与正文都不可交互；
关闭、Esc 或选定模块后归还导航入口焦点，旧的异步聚焦不能覆盖随后重新打开的抽屉。
环境部署页联网恢复后重新读取真实环境快照，不依赖顶栏探针或要求手动刷新。
已有读取尚未完成时合并为一次后续读取；再次断网或退出页面会释放待执行恢复。
持续的服务错误继续如实显示，不自动无限重试或把顶栏状态当作页面数据。
任务历史的紧凑列表保留完整的本地化状态，不能侵入路线数量单元格；
新建任务沿用控件库的主色与对比前景色，不为深色模式固定白色文字。
保存路线的名称／结构筛选由地址中的 `query` 管理，刷新与跨模块回退恢复同一筛选。
筛选仍只针对已加载记录，不把本地过滤冒充全库搜索，也不逐键重复读取后端。
异步打开路线预览前记录实际入口，正常关闭动画完成后返回可见入口；从任务信息
转入预览时，可返回对应的列表入口。跳转到详情／编辑、改变列表上下文、隐藏或
卸载所属页面时释放旧焦点，旧的关闭事件不能消耗下一次预览的入口，也不覆盖
关闭期间用户新选择的焦点。筛选变化使尚未完成的文档预览失效，不显示旧范围的
结果或让旧错误与忙碌状态覆盖新的读取。

## 化学工作流程约束

目标用户是药物化学与有机合成研究人员。所有页面按化合物、反应、原料与路线组织，
不要求用户理解图节点、JSON schema、库存哈希或搜索算法才能进行常规操作。
结构图与反应物到产物的关系是主要信息；SMILES、内部标识和运行详情为辅助信息。
搜索算法参数集中在高级设置；界面标题或默认模型用途标签不能改变实际参数、模型或质量门槛。

| 对象 | 常规输入与操作 | 文件边界 |
|---|---|---|
| 目标、原料、中间体 | 绘图、粘贴 SMILES、结构预览后应用 | MOL V2000/V3000、SDF、SMILES 文本文件 |
| 多化合物文件 | 逐页预览结构/名称/分子式/MW；显式选择一条 | 不默认取第一条，不自动批量提交推理任务 |
| 单个反应 | 同一画板内的反应物 → 产物；试剂/溶剂保留独立角色；多产物显式选择 | 单反应 MDL RXN 导入/完整导出；不解释为多步合成路线 |
| 完整路线 | 图形与正向合成步骤；原料查询、步骤详情、编辑副本 | X-Synth 路线 JSON；完整图 PNG；分子可单独导出 MOL/SDF/SMILES |
| 人工设计步骤 | 选择已有产物，逐条录入反应物并整体加入连接 | 保存为草稿，不添加模型分数、实验收率或商业闭合声明 |

化学文件通过 `/api/v1/structure/import`、`export`、`reaction-draft`、`reaction-import`、`reaction-export` 共用产品身份边界
与真实 RDKit 解析，不引入另一套名字解析、绘图推理或专用目标脚本。文件按 UTF-8 文本
处理，单次 2 MiB/100 条记录的读取保护拒绝超限而不截断内容；未写入任务历史或供应商数据库。
结构字段沿用现有原子数与 SMILES 长度上限。所有记录先完整验证，任何无效记录都会拒绝整个导入。
保留盐/离子组分、确定的立体化学、同位素和双键构型；未定义 R 基、查询结构、相对/混合
立体化学组与不支持的聚合物不得被转换成貌似确定的目标。分子式/MW 由当前结构计算，
多组分时为完整记录的结果，不自动只取主成分。导出执行结构身份回读检查，不假称保留原排版、
三维坐标、所有 SDF 属性、原图文本或 ChemDraw 专有注释。

RXN 的多个产物需显式选定一个评分产物；试剂/溶剂记录不会并入 FF 的反应物输入，
也不自动成为 NN 条件约束。导出仍保存整个反应的全部产物与试剂记录，不只导出所选产物。
结构验证与模型提交就绪分别管理：未选评分产物仍可导出完整 RXN，单侧 RXN 草稿可导入后继续绘图，
不能因此启动需要两侧结构的模型。转换到画板前必须对生成的 RXN 做完整身份回读；
当前格式不能无损保留的特殊立体化学或自由基表示明确拒绝，不接受后再擦除。
绘图或文件记录尚未确认时不能执行创建、加入步骤或评分；晚到的文件响应
不能覆盖新的结构、反应或文档。FF 是模型评分而非实验成功率。CAS 与名称只作为已有记录的身份信息，
未接入可靠名称解析服务时不能用 CAS/名称猜结构。CDX/CDXML、PDF 结构识别、ELN、
收率预测不能仅因参考软件有按钮而启用；已部署的条件模型有独立就绪探针与结构化结果。

正向步骤按真实前体依赖拓扑排序，所有分支在其产物后续步骤前出现。图标签与列表序号一致，
原始模型步骤索引、验证证据、模板来源和结果文件不被改写。循环或重复产物不能获得伪造的
正向顺序。界面中的“反应物”用于一个具体步骤，“起始原料”只用于整条路线的叶子；
没有采购记录的起始原料不自动标为商购。

路线总览、完整路线与编辑副本共享适应画布逻辑；宽路线可缩小到小屏画布范围内，
不能因固定缩放下限裁切目标或起始原料。缩略图保持整条路线，具体结构可在完整路线中
放大检查。缩放只改变显示，不改写分子坐标、步骤、原料或化学验证结果。
总览的选择与打开操作始终挂载，键盘可访问全部路线；只有较重的图形内容在进入可见区域后
延迟挂载，避免为全部离屏路线提前布局和绘制，不把延迟加载变成操作入口的阻碍。
缩略画布的高度按完整节点边界比例在 160–360px 内调整，选择框只占标题位置，不侵占
结构图的整列宽度。画布缩放、侧栏或检查器变化、从隐藏视图返回时重新适应完整路线；
用户明确定位的步骤由同一画布控制器管理，尺寸变化保留该焦点，点“适应画布”才返回全路线。
零尺寸及已释放的画布不执行适应操作。语言或分数更新不重置用户缩放，编辑拖动不自动
重新排版或修改保存的坐标。小屏缩略图展示完整上下文，具体结构仍在完整路线及步骤中查看。
路线详情中的化合物与反应缩略图提供只读放大窗口，支持缩放、适应窗口及滚动查看。
窗口复用同一结构绘图来源，不修改化学记录或推理证据；切换结构会关闭旧预览，正常关闭后
焦点返回原操作入口。需要修改时仍通过“编辑副本”进入现有路线编辑流程。
步骤中的化合物采用受约束的大幅结构图，详情入口与只读放大入口分开，不嵌套交互按钮。
只读放大复用一个绘图窗口和焦点控制器；缩放、适应窗口及关闭不选择或修改化合物，
同结构但不同记录的切换也会释放旧窗口。手机与桌面共用真实结构来源及可操作的触控尺寸。
核验摘要以独立标签和值区分步骤核验与参考覆盖；计数不合并为成功率，未知、未检索与
资料源不可用继续明确显示，不因排版美化隐藏科学边界。

保存的路线文档预览复用图形／步骤双层阅读。小屏打开含反应的文档时默认显示步骤，
图形页保留原坐标和原节点尺寸，完整适应画布不因步骤阅读而裁切。步骤列表和反应下拉框
不随图形缩放；结构图按可见区域延迟绘制，定位后返回步骤保留原滚动位置。图形初始化
完成适应操作后才应用第一次定位，避免初始全图覆盖用户刚选择的反应。步序按保存的
图节点 ID 拓扑投影，同 SMILES 的独立节点不合并；原反应名、备注、盐型、立体化学、
同位素与重复输入记录数保持原文。缺少连接的草稿明确显示缺失侧，不虚构产物、
预测分数、实验条件或库存闭合。文档标题和来源状态不等于路线已验证。
图形、步骤与检查器共用同一个按原图 ID 推导的显示序号，原反应名另行保留，不用名称
或 `r-N` ID 猜测序号，也不把显示序号写入文档。编辑器按当前已应用图计算，撤销后同步更新。
步骤与图节点的键盘入口同步保留原生事件，打开后进入详情，关闭后返回当前可见入口；
桌面鼠标查看不抢走阅读焦点。移动端详情使用单独阅读层，退出后恢复原步骤／画布。
切换语言或调整窗口尺寸不重置显式阅读视图；重新打开另一文档才应用对应初始视图。

文件互操作采用现有 [RDKit 文件解析接口](https://www.rdkit.org/docs/source/rdkit.Chem.rdmolfiles.html)
与 [Ketcher 分子绘图器](https://github.com/epam/ketcher) 的确定结构表达；不把最新版编辑器的
格式说明误当成本项目随带 2.13 版本的能力。内嵌和弹窗绘图板共享一个版本限定的响应式
适配器，移除原画板 640px 最小宽度并调整视图中心/缩放，不改第三方 bundle，也不修改
分子坐标来补偿窗口尺寸。验收检查实际结构边界，不以空白画布或页面无滚动条代替。
镜头按原生完整可见边界一次计算缩放，包含原子标签、反应箭头与注释；不叠加原生
骨架 fit 的额外缩小。小屏和宽屏共用同一适应与居中计算，清除旧滚动原点，仅平移
缓存的绘图元素，保持分子坐标、反应角色、当前选择和撤销历史不变。
原生手形平移仍由随带绘图器执行；视图适配器将纸面偏移量按当前倍率转换为浏览器
滚动像素，并保留滚动取整产生的亚像素余数，避免低倍率放大移动或高倍率累计误差。
用户滚动、倍率变化和显式适应窗口会清除旧余数；夹边的未执行移动不会累计为后续跳动。
纸面裁剪保留当前可见窗口，滚动目标超出时扩展原生纸面，不裁掉正在查看的区域；
原生倍率切换仍独立执行完整的同步锚点事务。显式适应先清旧滚动原点，允许纸面缩回，
不把反复平移形成的空白范围永久保留，也不重新导入结构来复位视图。
已有选择时，适应范围还包含原生选择框与旋转手柄的实际边界，不能只保证原子图可见
却裁掉编辑控件。未选择时不额外缩小结构，也不靠固定大留白补偿选择状态。
内嵌画板提供独立的缩小、适应、放大视图按钮；支持原生 Fullscreen API 的浏览器还可
放大同一个已挂载画板。放大／返回不另建 iframe、不重新导入结构或改写未同步的绘图。
视图请求、就绪后的窗口适应和焦点返回受同一当前操作约束；失败显示独立视图错误，
重试相同操作，不与结构读取／导入重试混淆。退出按钮和 Esc 均可返回，退出布局完成
且按钮恢复可用后再归还焦点。隐藏所属工作区或卸载只退出本画板拥有的全屏，不干扰
其他窗口；不支持该浏览器能力时不显示放大入口，普通缩放和适应仍可使用。
用户用视图工具或原生缩放控件手动缩放后，自动尺寸变化只重新居中、保留倍率，不因错误提示出现而
缩回全图；显式点击适应、初始导入或切换放大／返回视图时才重新计算完整绘图边界。
绘图视图工具栏只显示当前悬停或键盘焦点目标的一条提示；鼠标离开后恢复有效焦点的
提示，Esc 可关闭当前提示。禁用、切换放大状态或隐藏所属工作区会释放旧提示，
提示切换不保留相互遮挡的退场动画；按钮名称和键盘操作继续保留。
完整反应适应画布不设 10% 的缩放下限，小屏仍须保留全部结构与箭头；化合物可在
角色记录中逐项打开既有只读放大窗口，不以一张微小全图代替结构检查。
新文本／文件的初始反应图在试剂组分较多时，对生成的原生 KET 文档做紧凑排布。
组分分区来自已核验 RXN 的明确 R/P/A 顺序和完整化合物计数，不按坐标猜化学角色；
排布后须再次经真实 RDKit 回读，逐角色保留全部结构身份、重复记录、盐组分、
立体化学和同位素。排布与复核属于原有串行写入事务，未完成前不能执行或导出。
当前复核失败会恢复原始生成 RXN 并显示错误，不静默降级为成功；新输入和离开页面
取消旧复核，旧错误不能阻塞已成功的新结构。该排布只用于初始生成图，窗口调整和
用户缩放不重排化学坐标，也不改写原始输入、来源记录或已保存文件。
结构错误的重试仍由同一读写队列管理：导入／复核失败重试写入，画板读取失败则
重新读取当前未同步绘图，不用最后一次已接受的文字静默覆盖用户的新绘图。
错误、待选产物与待确认文件继续阻止执行，但不冒充仍在运行的 `aria-busy` 状态。
原生导入超时或中断后，原画板不能继续接收写入；相同错误提供“重新加载画板”，
显式创建新的原生实例并重新订阅绘图变更。恢复使用当前文本，不使用最后一次已接受
的旧结构；完成真实导入、反应身份复核和适应窗口前继续禁止提交。绘图读取失败仍
在原画板上重读，不重建或擦除尚未同步的新绘图。退出所属组件取消重载后的迟到响应。
原生文档离开时立即释放旧读取和变更订阅，不能等超时后才阻止旧结构提交。
新文本在新画板完成导入后绑定其变更订阅，不沿用已离开的原生实例；旧导入的迟到事件
不能隐藏恢复入口。过期的读取释放当前忙碌占用并返回失效结果，不继续阻塞宿主调用者；
不声称取消原生解析或收到新结果，迟到的原生响应仍不能发布或解除新操作的忙碌状态。
宿主读取的失效与原生操作串行分别管理：同一原生实例的导入和导出不能因宿主失效
而重叠，避免随带转换器按消息类型分发时错接旧结构。导入占用持续到真实终态，
不以早返回的 SDK Promise 为完成依据；排队与导入共享既有截止时间，过期排队
不会再写入旧画板。真正新建的画板使用独立队列，解析接口与复合复核不占原生队列，
避免嵌套死锁。原生工作仍在运行时保留其交互阻塞；中断恢复不受旧实例阻塞。
错误和恢复入口置于画板上方。没有后续用户操作的键盘重试，完成后聚焦可见的
适应窗口按钮；用户继续输入、切换或点击其他区域时不抢回焦点，原生初始化的
隐藏剪贴板也不能覆盖最新文本输入意图。指针重试不强制移动焦点。

结构录入统一以 Ketcher 内嵌画板为主，上方常显两行 SMILES 粘贴框；放大绘图仍使用同一
随带版本。绘图修改经过串行读取后回写当前 SMILES，文本/文件导入等待真实解析完成，
同步、读取、失败或文件选择未确认时禁止提交旧结构。晚到的画板读取不能覆盖新的输入。
准备、原生导入与画板上下文应用同属一个串行写入事务，读取等待整个事务结束。
模型运行导致的禁用只取消读取，不废弃最新结构写入；读取上下文只在当前响应确认发布后更新。
反应检索、条件推荐与 FF 采用统一单反应画板，上方保留紧凑的反应 SMILES 框。
画板只接受一个反应箭头；角色通过 Ketcher 原生反应导出和 RDKit 解析取得，不按画面坐标或
手写字符串拆分猜测。文本先解析并生成完整 RXN 载入，不把原编辑器无法理解的分组表达直接交给它。
明确的手性以绝对 CTAB 分组写入，未知手性不补齐。随带 Ketcher 2.13 会拆开断开的盐组分，
因此用户从 RXN 或扩展 SMILES 明确声明的完整化合物分组保存在当前画板的解析上下文；
回读必须精确核对同一角色下每个组分的手性、同位素、电荷与重复计数，再恢复声明。
没有声明不猜盐；改变声明中的组分或移到另一个反应角色必须重新确认，不能继续提交旧结构。
删除现有反应的箭头也不能把两侧结构偷偷并成一个产物。反应输入允许不完整草稿，
但条件推荐与 FF 要求明确反应物及所选产物；检索也可只输入产物。RXN 导入先展示所有角色，
经用户确认后应用；失败不改画板。多个产物不默认取第一条，已选身份仅在新草稿仍包含它时保留。
这复用 [CAS SciFinder 的反应绘图输入思路](https://www.cas.org/training/lesson/search-reactions-with-drawn-structures-in-cas-scifinder)，
不意味着接入 CAS 数据库。当前后端是精确产物召回并核验反应物身份，不提供反应物单侧查询、
反应中心、亚结构或相似反应搜索；界面不创建对应的无效模式。完整反应输入与产品执行仍走原来的
检索、条件与 FF 接口，不增加平行模型链路。产物预测仍使用单个反应物画板，单分子页面不变。
重复物料中的画板按可见区域延迟初始化，离屏且同步完成后释放 iframe，重新进入时恢复已同步的
结构；未完成编辑与错误仍保留，不丢弃输入。只读路线、检索结果和
文件多记录选择仍采用 RDKit 预览，不把每个结果装成编辑器。既有路线和化学验证门禁不变。

## 导航组织

桌面默认使用横排图标与本地化标签，可收起为紧凑侧栏；窄屏仍使用可关闭、
支持焦点约束的导航抽屉。路线设计及反应输入工作台共用左侧参数、右侧结构画板的
表单布局，窄屏先展示化学输入，再展示参数与提交操作。绘图板在模式切换时保持挂载，
打开路线文档不销毁未提交的目标结构。视觉样式按设计变量、基础规则、导航壳和
内容表面分模块维护，只有一个公共样式入口，不增加另一套绘图或模型执行路径。

### 页面层级

页面按任务性质建立层级，而不是把输入、空结果、完整明细永久平铺：计算类采用
录入 → 已保存结果 → 详细依据；检索类保留筛选与列表并进入选中记录；路线阅读采用
总览 → 单条路线 → 步骤 / 原料 / 来源；编辑器保留完整画布与按需检查器；部署和管理
采用主题分区。共享层级不意味着所有工具都套成向导，也不启用缺少后端的功能。

单步逆合成在同一工作台中区分目标输入与候选比较；生成后打开比较层，仍复用原生
候选分页、预览与编辑副本，画板保持挂载。目标或模型、模板数量、FF 参数的真实编辑
会使旧候选失效，同一时刻改动后恢复原值也不能复活旧结果。只有当前提交所拥有的
原生画板读取可以更新结构文本表示；过期读取和结果不能覆盖新目标。这里仍是单步
前体候选，不宣称完成商购闭合；会话草稿不等于已保存的任务或完整合成路线。

路线总览显式进入单条或所选路线后，显示并聚焦当前路线的导航；返回总览恢复原
路线入口与滚动位置。被动结果刷新不会抢夺焦点。反应箭头也提供命名原生按钮，
键盘 Enter/Space 与点击走同一详情事件链，节点尺寸、连接及化学记录不改变。
模板详情保留但隐藏上一层筛选表单，优先显示模板身份、原有反应预览，再展开元数据
和参考记录；从列表进入时显示返回入口，回来保留真实查询、游标、展开行与阅读位置。
路线编辑器保留全幅画布和名称编辑框，同时提供与当前名称绑定的无障碍页面标题。
检查器中尚未应用的名称、结构和备注是独立草稿：关闭、换结构、覆盖内容或离开前需确认，
单纯移动图形不会重置草稿，也不会把草稿自动保存。绘图同步与 Apply 共同构成忙碌状态，
尚未同步的结构不能被关闭、切换或丢弃。Apply 成功后才进入可保存的已应用图；状态提示
区分未应用、未保存与已保存。版本冲突使用完整中英文提示，支持明确确认后的重新载入
及另存副本；不会更新 revision 后偷偷重试覆盖。重新载入失败保留现有标题、图和草稿，
恢复连接后仍可从同一入口继续；旧请求不能覆盖后来打开的文档。

工艺核算的录入分为产物与批次、投料与计量、其他出料。切换分区保留当前输入，
不挂载第二个空结果面板。相邻分区提供前后操作，直接选分区和键盘切换使用同一
标签 / 面板契约；相邻操作聚焦新的录入层，未确认的物料编辑或结构同步期间不切走。
批次重置或分区变化后，已排队的相邻操作不再聚焦旧分区。
分区标签与工具导航共用局部横向可见性规则。相邻操作、语言切换、窗口改变后，
当前分区仍须可见；被动更新不抢焦点、不滚动外层页面。手机端路线设计的三个模式
均显示完整入口，不用被裁切的文字作为进入单步分析或导入文档的唯一途径。
不强迫每个批次填写可选出料；核算仍提交完整当前批次，而不是只提交可见分区。
物料行只显示紧凑结构预览、角色、质量与单位；编辑时才
打开 Ketcher，点击应用后写入该物料，取消或晚到的读取不能覆盖原行。结构读取失败
不会变成空结构；清除结构是单独的明确操作，不删除质量、单位或批号。
清除采用具名标准图标，物料编辑和移除操作保持可用触控尺寸；窄屏弹窗将应用操作
放在独立一行，正文可滚动，不裁掉底部操作。显式应用可规范化 SMILES 表达顺序，
但不改变分子身份，也不改写原已提交批次。
用户核算失败后定位本次错误；重复提交相同错误也重新定位。输入变更、批次重置或
组件退出后，已失效的提交不会抢夺新上下文的焦点，错误不清空所录入物料。

工艺核算、结构评估、反应条件、产物预测、杂质分析与实验优化成功后打开既有 `/analyses/:id` 结果页面；服务器记录仍是唯一
计算结果来源，不增加浏览器结果库。结果页的“返回修改”通过 `?record=<id>` 回读
已提交输入，保留完整结构、盐组分、数量单位、零值、未知值及指定计量依据。
浏览器当前历史位置只保存已提交记录的 ID、类型与原页面位置，用于普通返回和刷新；
它不保存结构或实验输入正文，也不覆盖不同 URL 的新目标。修改后重新核算产生新记录，
不改原记录；尚未提交的编辑不是自动持久化的实验记录。

条件预测另外保存经 RDKit 核验、与提交反应物及所选产物绑定的完整反应上下文，
返回修改时恢复所有产物和试剂记录及明确的选择。上下文不是 NN 的条件约束，也不
改变模型调用。旧客户端仍可不传；旧记录只恢复原先实际提交的反应物和所选产物，
页面明确说明范围，不虚构缺失的画板。杂质回放逐条恢复原子贡献反应物、已知主产物、
试剂、溶剂和候选数量。读取期间禁止编辑，错误提供重读，不使用迟到响应覆盖新输入。
结果刷新只读已有记录；FF 可行性复核需另行明确点击，不在历史浏览时自动执行。
研究结果页将日期、状态与化学结果置于主阅读层，内部记录标识留在原始输入披露内。
同一已完成记录通过重新读取和完整 DTO 校验后，仅当整份快照不变时保留结果对象的
引用与子视图阅读位置；变化的输入、来源、状态或元数据发布新对象。读取失败、身份
拒绝或无效响应清除旧快照，不把旧内容标记为新结果。读取的取消与超时仅限当前 GET，
不取消或缩短后台科学任务。
如果结果已保存但自动跳转失败，输入页保留打开该记录的入口，不把重试当作已保存记录的修改。

批次结果优先显示产物身份和关键指标，明细分为核算总览、物料明细、核算口径。
完整边界 PMI 与不完整投料的 PMI 下限、分离总质量与纯产物质量、录入与计算收率
始终分别标注。参考定义、缺失依据和原始输入可进一步展开；缺少数据不填零或猜纯度。

同样的层级按页面性质使用，不叠加重复的“工作台主页”：

| 页面类型 | 主层 | 下一层 | 保留的上下文 |
|---|---|---|---|
| 研究计算 | 化学 / 批次 / 实测表录入 | 已保存结果 → 明细与依据 | 返回修改回读原记录，不改旧计算 |
| 原生即时评分 | 输入结构或反应 | 当前只读评分 → 计算依据 | 保留并隐藏画板；无记录服务时不声称持久保存 |
| 路线任务 | 目标与搜索配置 | 任务状态 → 路线总览 → 单条路线 → 步骤、来源、原料 | 当前快照、原始路线身份、选中路线 |
| 模板与参考检索 | 查询与候选列表 | 选中模板或反应 → 来源记录 | 筛选、游标、返回位置与结构身份 |
| 库存检索 | 化合物查询 | 精确结构命中 → 供应商目录记录 | 目录快照，未知供货 / 价格保持未知 |
| 路线编辑 | 全幅化学画布 | 按需检查器、绘图 / 步骤编辑窗口 | 文档版本与草稿；编辑副本独立于模型输出 |
| 环境与账号 | 按主题的运行 / 身份视图 | 可用配置、监测或已授权账号操作 | 实际就绪与服务端权限，不创建未部署功能 |

商业原料检索分为查询、目录记录、证据详情。提交后优先打开目录记录层，原画板保留，
不把结果放在输入画板之后；返回修改继续原结构和任务快照。每条供应商目录记录可
单独打开证据，返回聚焦原记录入口。结构或快照变化、尚未确认的绘图 / 文件输入
会作废旧结果，迟到响应不能恢复；没有精确记录只展示查询结构，不称为采购命中。
当前目录与任务快照不同的提醒在阅读层常显；目录价格、交期和缺失字段仍按原证据，
不推算实时供货、采购资格、最低价或未知货币。证据详情先显示规范化结构与选中供应商，
完整查询与快照标识可展开检查。新查询清除当前查询与任务快照以及 URL 中的
`smiles`、`q` 和 `snapshot`，避免刷新重新载入旧查询，不删除任务、记录或供应商数据。

结构评估结果以完整化合物身份为首层，阅读分为核心事实、组分复杂度、完整描述符、
方法与来源。所有科学解读限制、组分提示和未指定立体中心始终可见，不被标签切换
隐藏。单组分可摘要原有复杂度指标，多组分逐一报告，不生成整条盐记录的综合 SA。
所有结构事实、描述符、方法实现、许可和原始来源链接均保留；零、未定义与未记录
分别呈现。结构图原子数沿用 RDKit 分子图计数，不把分子式中的隐式氢补入该字段。
这里只改变已保存结果的阅读组织，既不重算历史，也不增设结果存储。

原生 FF 与 SCScore 的结构输入和当前评分也分为录入与只读评分层；计算完成后
保留但隐藏并锁定画板，显示本次完整结构、模型计算值和按需展开的计算依据。
返回修改清除当前评分并恢复原画板；真实结构变化使旧分数失效，隐藏画板的回收
不会改写科学输入。它们仍使用原生同步接口，尚无研究记录 API，不假称评分已保存，
刷新重新进入输入层。模型计算值与实验验证不同，不能标为实验成功率。

实验优化输入页只保留实测表、明确选择的实验行、因子水平和响应配置，计算成功后
独立打开下一批实验结果。输入按实测记录、因子与响应、下一批确认分层，切层保留
当前草稿及确认状态；配置层的 Enter 不提交隐藏推荐。全部 / 已选阅读各自保留页码，
筛选不自动选行，响应与因子列明确标识，原行号、零值和列名不改写。
因子水平修正不关闭编辑器；过限选择恢复真实的原生复选状态。切层、CSV / 上下文
变化或退出后，旧导航不再聚焦。控制器不以系统提示充当未知文件名，非空用户文件名
始终原样显示；仅未记录文件名的历史回读采用本地化说明。返回修改或浏览器后退先读取原研究记录并重新解析原始 CSV，
核对 SHA256 后恢复所选行、因子类型及水平、响应类型/方向/单位、批次大小和随机种子；
两项实验确认清除，必须针对当前输入重新确认。输入读取或核验失败时锁定提交并允许重读，
不以旧表格或默认参数替代。结果页显示输入摘要，完整因子与技术标识按需展开，原始 CSV
和建议 CSV 分别下载；原始文件字节保留，缺失的原文件名不猜测。刷新已有结果只读取记录，
不重新拟合；返回修改产生的新计算也不会改写原记录。大型原始输入仅在展开时渲染。
各计算输入页的“新建”显式清除当前输入及该历史位置的恢复指针，即使 URL 不变也有效；
不会删除原服务器记录。UTF-8 CSV 的 BOM、换行和引用字节保留至原始文件下载。
响应列不因未选记录中的“待测”等文字而被隐藏。数值、范围及条件空间检查仍由原有后端
对显式选中的实测行执行，验证失败不会启动 BayBE，不读取未选行的响应用于训练。

### 前端品质标准

设计目标是专业科学工作台的高品质，而非以动画、宣传页或自评代替真实可用性。
参考 [Awwwards 的设计、可用性、创造性与内容标准](https://www.awwwards.com/about-evaluation/)
和 [Webby 的导航、视觉、功能、交互与整体体验标准](https://www.webbyawards.com/judging-criteria/)，
获奖需由外部评审决定，不能通过单次构建或内部评分声明已达到。

共享设计规则位于 `apps/web/src/styles`：tokens 管理颜色、字体、尺寸与动效，foundation
管理基础排版、键盘焦点及减少动画，shell 管理导航与视口，surfaces 管理表单、表格与状态。
页面局部规则只负责自身布局，不建立第二套主题；技术详情、账号菜单和弹窗同样遵守这些规则。

工作区将健康与会话作为一对原子快照发布，模板、实验优化和参考资料探测独立更新；
较慢的可选来源不能拖延已确认的核心就绪，也不能在后台轮询时销毁已经初始化的输入。
不可用的输入子树仍隐藏、不可交互并退出无障碍树；恢复继续原草稿，路径或功能范围
变化才重新初始化。已打开的化学选择 / 绘图窗口同样受该隐藏与焦点边界控制，不泄露到
失效页面之外。仅初次或该功能自身尚未确认时显示连接状态，已知失败不显示“连接中”。
浏览器从离线恢复联网时立即请求一次真实就绪复查，不等待下一次定时轮询；若旧探测
尚未结束，仅取消旧的只读探测，重复重连请求合并为同一次后续复查。复查仍走原健康与会话快照门禁，
不能因联网事件本身显示就绪或重新提交任务，也不清除已有化学输入。
连接错误使用所选界面语言；只有实际确认原生会话模式才显示账户入口，不把会话
缺失或探测失败视作原生身份，也不因本地断线而添加账户入口。
具备工作区范围的化学窗口将所属草稿与可见弹窗分开管理：后台分区或断线时暂停
可见弹窗并退出全局活跃栈，但不触发取消，不清除文件、选中记录或未提交画板。
恢复重新取得正确的 Esc / 焦点顺序；正常关闭仍释放窗口子树与画板资源。
菜单挂载和暂停使用统一策略：菜单位于所属工作区、子页或化学窗口内，不能困在单个
输入框的布局隔离层中；所属 DOM 容器注册后才挂载内容。隐藏选择框退出全局菜单活跃栈，
保留选择值和科学输入。化学窗口内部重新应用该策略，窗口暂停时其产物选择菜单也暂停；
活动选择框仍保留自身禁用和空选项行为，不用全局默认值覆盖。
范围外的路线预览 / 编辑保持原弹窗挂载位置，不能因工作区门控改变整个应用的定位。
溶解度与溶剂的异步失败保留在所属分区内，不从隐藏分区弹出全应用错误窗口；
未部署的原生服务仍不启用，不以组件协议检查代替实际模型或身份验收。

所选菜单；提交及文件读取期间锁定参数，清空或离开页面会取消当前请求。溶剂筛选的

迟到的结果、错误和结束通知不能影响下一次提交。历史结果行仍保留各自模型与科学字段。

未启用的 QM 模型仍不开放计算，也不以界面协议检查声明模型已经验收。
结构绘制页的应用、清空与标准化
也检查尚未确认的文件选择与画板同步，不能只靠弹窗遮挡来防止处理旧结构。

标准化请求、原生写入与确认回读均成功后才发布已标准化状态。失败保留此前已应用预览。

正在运行的原生操作与未就绪画板继续阻止危险操作。自动同步画板只有收到当前原生
画板的新编辑事件并成功回读后，才解除该画板已结束的失败写入，不把失败导入改为成功。
中断导入或原生写入成功后的角色／布局核验失败仍必须重新加载，旧画板、
未确认的反应角色分组或过期回读不得发布结构。

离开页面取消所属旧解析请求。超时不改为成功，未确认结果仍不能执行；用户可修正或
重新导入。这个期限只用于确定性输入处理，不缩短路线搜索或模型任务的预算。
反应输入的解析错误、文件处理状态及缺少角色／待选产物提示紧邻 SMILES 输入，
多产物确认位于画板之前；文件失败不把未改变的原反应文字标成无效。RXN 导入期间
可明确取消，保留原反应并返回导入操作；参考反应沿用原有上层取消，不增加竞争入口。
导入与导出共用一个操作状态来源；导出显示所属进度，不暴露能误取消下载的导入按钮。
被动提示不抢焦点。分子评估的请求错误和已保存结果恢复入口紧邻实际计算操作，
窄屏不用从提交处反向寻找画板上方的失败信息。
原生账号入口等待同一次探测的核心快照，不等无关可选来源；普通用户只能操作自己的
受支持资料，管理员功能仍需服务端权限。身份 / 权限失效立即清空私有账号内容，不能
用浏览器 token 的存在或本地工作区管理员标志代替原生身份验证。
禁用规则集合、单条 / 批量草稿、确认窗口与每次写入都绑定已验证的原生账号及权限。
账号变更清除私有集合和草稿，迟到读取不再发布，确认后和逐条批量发送前重新检查同一
范围；同账号短暂失联可以保留草稿，但旧请求不会复活。批量 JSON 在发送前完整验证，
2 MiB / 100 行及原生字段长度超限明确拒绝、不截断；读取、解析或行错误释放忙碌状态并
允许重试。已发送的服务端变更不能靠取消撤销，部分失败使用实际成功 / 失败计数。
Esc、遮罩和关闭按钮沿同一真实关闭流程取消单条 / 批量窗口的在途操作；工作区暂时
隐藏不会触发此取消。成功提交先刷新所属集合再关闭，关闭后迟到通知不能改写当前草稿。

长期开着的页面不会自动换成部署后的新代码。已接入版本提示的工作台在确认 API 版本
高于所载入前端时显示“打开新版”，用相同站点、相同当前路由另开页面；不自动刷新，
不复制实验输入，不销毁旧标签里的未提交编辑。版本比较遵循产品的补丁 / 次版本进位
规则，不对缺失、异常版本或暂时失联猜造更新。

绘图器的原生编辑与 SMILES 辅助字段保持同步，清空画板不能留下旧目标文字。
结构同步、文件选择或错误尚未处理时禁止提交；这与模型是否就绪分别展示，
输入问题不能被标为计算服务不可用。结构同步失败保留错误和提交门禁，但停止
无实际操作的进度动画。画布大小变化后重新适配当前结构，并通过原生视图事件
更新缩放文字；不改分子坐标、选择或撤销历史，不以化学修改事件刷新工具栏。

只读结构的复制入口支持键盘操作，并在实际写入成功后才显示“已复制”；权限拒绝或

模板列表保留展开内容，返回时恢复原记录的焦点与阅读位置；索引总量、本次返回数量
和查询上限分别显示，不把有上限的结果列表声称为完整模板库。
完整模板浏览使用同一知识服务的真实游标分页，每页最多 500 条，但不限制整个匹配集合
为 500 条。结果按反应例数降序、来源和模板标识升序排列；过滤匹配总数与本页数量
来自同一不可变索引读取，不从已加载记录推算全库规模，也不改变训练模板的原编号。
游标绑定索引快照、实际过滤条件和存在于该集合的起始位置，支持同一快照下的重启续页。
它只保存查询位置，不是登录凭据或采购证据；无效游标返回 422，已变更快照返回 409，
不能静默回到首批或混合两个集合。恢复时需要用户明确重新检索。
列表链接保留当前游标和条件，刷新与浏览器返回读取实际页面；只在当前会话中确实
知道前一页时开放上一页操作，不为外部链接猜造页码。分页历史只保留有上限的边界
信息，不在浏览器堆积整个模板库。桌面长列表保持筛选区可达，小屏与短窗口正常滚动。
没有对应方向的索引覆盖时明确禁用该方向，不将未部署的模板集合显示为普通零匹配。

不将未提交的输入自动变成查询。索引和详情读取使用可取消的 15 秒请求；离开页面、
切换记录或新一轮读取后，旧响应与已释放页面的重试回调不能重新发布状态或发起请求。
详情以反应预览和试剂／限制为主，参考记录及技术字段分层展示。SMARTS、原生编号、
属性及全部引用原值仍可检查；内部数字引用不补猜成文献。切换语言不重新取数或重置
参考分页；程序生成的索引错误、记录不存在和游标错误使用同一中英文资源。
模板绘图保留真实查询原子的元素、查询条件和映射；泛化标签只改变显示，不把查询原子
改成虚拟原子。单个产物的链接预览使用分子格式，完整反应链接使用反应格式。
参考反应确认预览暂时禁用执行与导出；取消且结构未改变时保留查询结果，
真正修改、应用新反应或切换查询仍使旧证据失效。
文献与原始数据链接独立提供，并沿用安全 URL 门禁；不存在的链接不补猜。
目录交期按原始快照字段显示，缺项保持未记录，不等于实时供货承诺；任务与当前目录
快照不一致时在结果上方常显提醒，完整标识仍置于技术详情。

研究记录复用工作区的条件与产物结果组件，不显示可再次执行的历史验证按钮。
名称或编号等结构未确认的标签明确保留其身份边界。实验优化的历史表格与工作区
共享样式，CSV 导出使用已保存的原始内容，不重新生成预测或填充实测值。
实测行选择被容量门禁拒绝后，页首选择框必须回到真实选择状态；数据视图标签与
面板关联，支持键盘方向键切换，保持一个主内容地标。
环境页的标签与稳定面板标识关联，只有当前面板呈现内容；库存健康明确区分已通过、
未通过与未读取，不把未知信息当作失败。源码验收中的 Git 查询禁用可选索引刷新，
保持范围选择器只读，不替代真正暂存和提交所需的写锁。

验收同时检查默认、实际结果、空、加载、错误、菜单和弹窗。测试按改动和直接消费者选择，

浏览器自审需要保留真实页面截图和失败记录，修复后再捕获；不以模拟任务填充科学结果。

| 任务历史 | 分组 → 全库名称/结构/状态筛选 → 卡片或列表 → 批量移组/归档/恢复 → 参数/预览 | 页与计数同一事务；标题与分组是独立历史元数据，不改变搜索输入或运行 revision；刷新及返回保留筛选 |
| 任务详情 | 完整路线列表 → 勾选路线 → 路线标签 → 图形/步骤/反应条件/物料清单 → 节点详情 | 预览弹窗和完整详情共用 RouteReader；排序与选择始终保持原路线索引，状态和路线文件独立加载 |
| 分子节点 | 节点 → 采购记录 → 完整原料检索/供应商目录 | 精确结构匹配；显示查询快照并比较原任务快照；不伪造 CAS、报价或包装 |
| 分子节点 | 节点 → 一步分析/结构复杂度 | 只预填所选结构，不自动推理，不修改原始路线 |
| 反应节点 | 节点 → 反应结构 → 可行性计算 | 反应物与产物来自实际图连接；模型响应失败不是无候选 |
| 反应节点 | 来源模板 → 模板详情 → 返回检索 | 来源与 ID 共同定位；训练序号与内部反应引用不能猜成模板 ID |
| 反应节点 | 实际反应 → 路线内条件弹窗/专利参考反应 → 研究记录或引用详情 | 打开弹窗不计算，显式预测才调用共用 NN 模型；关闭返回原路线与步骤；USPTO 原记录与 NN 预测分开 |
| 模板详情 | SMARTS/限制/参考记录 → 已明确的公开链接 | DOI、专利与 HTTP 链接校验；数字内部引用只显示原值 |
| 原料检索 | 预填/手输 → 验证 → 结构与记录一起提交显示 | 新查询失败或晚返回时不能将旧供应商记录挂在新结构上 |
| 路线文档 | 预览节点 → 编辑 → 应用 → 保存/导出 | 验证完成前固定节点与输入；切换节点后旧结果不能写入新节点 |
| 路线文档 | 未保存画布 → 打开路线文档 JSON | 用户确认前不创建导入文档、不清除修改、不跳转 |
| 路线文档 | 保存状态 → 科学状态 → 原始任务 | 保存成功与来源副本/草稿分开；修改化学结构使原计算声明失效 |
| 原生历史 | 历史记录 → 共享预览/详情 → 编辑副本 | 原生 UDS 用同一解码器投影；原文件保留，不重新认证商业闭合 |
| 环境部署 | 当前引擎 → 原生能力 → 未接入软件 → 数据依赖 | 只展示真实接入状态，未启用模块不是功能按钮 |
| 反应与条件 | 反应结构 → 参数 → 显式提交 → 候选 → 研究记录 | 输入变化使旧响应失效；两种模型评分不混作实验验证 |
| 杂质候选 | 反应物、已知主产物与试剂/溶剂 → 确认输入 → 五模式分析 → 结构与来源 → 研究记录 | 原子映射检查必须执行；已知产物是用户参照，不伪造其模型分数；不推断杂质含量 |
| 结构评估 | 化合物 → 计算 → 组分指标 → 方法来源 → 研究记录 | 完整结构身份与各组分分开；Na 等无机组分不造 SA 分数 |
| 工艺核算 | 产品/投料 → 质量单位/边界 → 计算 → 物料与 PMI → 研究记录 | 分离总质量、质量纯度和录入收率分别保留；不自动补全未知项 |
| 实验优化 | 真实 CSV → 选择记录 → 因子/响应 → 确认候选空间 → 独立结果 → 返回修改/分别导出 | 原始表 SHA256、所选行、条件空间、随机种子和模型版本绑定；返回后重新确认，建议 CSV 的实测响应保持为空 |
