# X-Synth 工作区交互与能力边界

产品版本为 0.1.0。业务界面使用 X-Synth 品牌；后端引擎、模型和模板来源在环境清单与
技术详情中保留。浏览器请求只进入产品 API，不绕过任务编排、身份与采购证据门禁。

## 化学工作流程约束

目标用户是药物化学与有机合成研究人员。所有页面按化合物、反应、原料与路线组织，
不要求用户理解图节点、JSON schema、库存哈希或搜索算法才能进行常规操作。
结构图与反应物到产物的关系是主要信息；SMILES、内部标识和运行详情为辅助信息。
搜索算法参数集中在高级设置；界面标题或默认模型用途标签不能改变实际参数、模型或质量门槛。

| 对象 | 常规输入与操作 | 文件边界 |
|---|---|---|
| 目标、原料、中间体 | 绘图、粘贴 SMILES、结构预览后应用 | MOL V2000/V3000、SDF、SMILES 文本文件 |
| 多化合物文件 | 逐页预览结构/名称/分子式/MW；显式选择一条 | 不默认取第一条，不自动批量提交推理任务 |
| 单个反应 | 同一画板内的反应物 → 产物；试剂/溶剂保留独立角色；多产物显式选择 | 单反应 MDL RXN 导入/完整导出；不解释为多步合成路线 |
| 完整路线 | 图形与正向合成步骤；原料查询、步骤详情、编辑副本 | X-Synth 路线 JSON；完整图 PNG；分子可单独导出 MOL/SDF/SMILES |
| 人工设计步骤 | 选择已有产物，逐条录入反应物并整体加入连接 | 保存为草稿，不添加模型分数、实验收率或商业闭合声明 |

化学文件通过 `/api/v1/structure/import`、`export`、`reaction-draft`、`reaction-import`、`reaction-export` 共用产品身份边界
与真实 RDKit 解析，不引入另一套名字解析、绘图推理或专用目标脚本。文件按 UTF-8 文本
处理，单次 2 MiB/100 条记录的读取保护拒绝超限而不截断内容；未写入任务历史或供应商数据库。
结构字段沿用现有原子数与 SMILES 长度上限。所有记录先完整验证，任何无效记录都会拒绝整个导入。
保留盐/离子组分、确定的立体化学、同位素和双键构型；未定义 R 基、查询结构、相对/混合
立体化学组与不支持的聚合物不得被转换成貌似确定的目标。分子式/MW 由当前结构计算，
多组分时为完整记录的结果，不自动只取主成分。导出执行结构身份回读检查，不假称保留原排版、
三维坐标、所有 SDF 属性、原图文本或 ChemDraw 专有注释。

RXN 的多个产物需显式选定一个评分产物；试剂/溶剂记录不会并入 FF 的反应物输入，
也不自动成为 NN 条件约束。导出仍保存整个反应的全部产物与试剂记录，不只导出所选产物。
结构验证与模型提交就绪分别管理：未选评分产物仍可导出完整 RXN，单侧 RXN 草稿可导入后继续绘图，
不能因此启动需要两侧结构的模型。转换到画板前必须对生成的 RXN 做完整身份回读；
当前格式不能无损保留的特殊立体化学或自由基表示明确拒绝，不接受后再擦除。
绘图或文件记录尚未确认时不能执行创建、加入步骤或评分；晚到的文件响应
不能覆盖新的结构、反应或文档。FF 是模型评分而非实验成功率。CAS 与名称只作为已有记录的身份信息，
未接入可靠名称解析服务时不能用 CAS/名称猜结构。CDX/CDXML、PDF 结构识别、ELN、
收率预测不能仅因参考软件有按钮而启用；已部署的条件模型有独立就绪探针与结构化结果。

正向步骤按真实前体依赖拓扑排序，所有分支在其产物后续步骤前出现。图标签与列表序号一致，
原始模型步骤索引、验证证据、模板来源和结果文件不被改写。循环或重复产物不能获得伪造的
正向顺序。界面中的“反应物”用于一个具体步骤，“起始原料”只用于整条路线的叶子；
没有采购记录的起始原料不自动标为商购。

路线总览、完整路线与编辑副本共享适应画布逻辑；宽路线可缩小到小屏画布范围内，
不能因固定缩放下限裁切目标或起始原料。缩略图保持整条路线，具体结构可在完整路线中
放大检查。缩放只改变显示，不改写分子坐标、步骤、原料或化学验证结果。
总览的选择与打开操作始终挂载，键盘可访问全部路线；只有较重的图形内容在进入可见区域后
延迟挂载，避免为全部离屏路线提前布局和绘制，不把延迟加载变成操作入口的阻碍。
路线详情中的化合物与反应缩略图提供只读放大窗口，支持缩放、适应窗口及滚动查看。
窗口复用同一结构绘图来源，不修改化学记录或推理证据；切换结构会关闭旧预览，正常关闭后
焦点返回原操作入口。需要修改时仍通过“编辑副本”进入现有路线编辑流程。

文件互操作采用现有 [RDKit 文件解析接口](https://www.rdkit.org/docs/source/rdkit.Chem.rdmolfiles.html)
与 [Ketcher 分子绘图器](https://github.com/epam/ketcher) 的确定结构表达；不把最新版编辑器的
格式说明误当成本项目随带 2.13 版本的能力。内嵌和弹窗绘图板共享一个版本限定的响应式
适配器，移除原画板 640px 最小宽度并调整视图中心/缩放，不改第三方 bundle，也不修改
分子坐标来补偿窗口尺寸。验收检查实际结构边界，不以空白画布或页面无滚动条代替。

结构录入统一以 Ketcher 内嵌画板为主，上方常显两行 SMILES 粘贴框；放大绘图仍使用同一
随带版本。绘图修改经过串行读取后回写当前 SMILES，文本/文件导入等待真实解析完成，
同步、读取、失败或文件选择未确认时禁止提交旧结构。晚到的画板读取不能覆盖新的输入。
准备、原生导入与画板上下文应用同属一个串行写入事务，读取等待整个事务结束。
模型运行导致的禁用只取消读取，不废弃最新结构写入；读取上下文只在当前响应确认发布后更新。
反应检索、条件推荐与 FF 采用统一单反应画板，上方保留紧凑的反应 SMILES 框。
画板只接受一个反应箭头；角色通过 Ketcher 原生反应导出和 RDKit 解析取得，不按画面坐标或
手写字符串拆分猜测。文本先解析并生成完整 RXN 载入，不把原编辑器无法理解的分组表达直接交给它。
明确的手性以绝对 CTAB 分组写入，未知手性不补齐。随带 Ketcher 2.13 会拆开断开的盐组分，
因此用户从 RXN 或扩展 SMILES 明确声明的完整化合物分组保存在当前画板的解析上下文；
回读必须精确核对同一角色下每个组分的手性、同位素、电荷与重复计数，再恢复声明。
没有声明不猜盐；改变声明中的组分或移到另一个反应角色必须重新确认，不能继续提交旧结构。
删除现有反应的箭头也不能把两侧结构偷偷并成一个产物。反应输入允许不完整草稿，
但条件推荐与 FF 要求明确反应物及所选产物；检索也可只输入产物。RXN 导入先展示所有角色，
经用户确认后应用；失败不改画板。多个产物不默认取第一条，已选身份仅在新草稿仍包含它时保留。
这复用 [CAS SciFinder 的反应绘图输入思路](https://www.cas.org/training/lesson/search-reactions-with-drawn-structures-in-cas-scifinder)，
不意味着接入 CAS 数据库。当前后端是精确产物召回并核验反应物身份，不提供反应物单侧查询、
反应中心、亚结构或相似反应搜索；界面不创建对应的无效模式。完整反应输入与产品执行仍走原来的
检索、条件与 FF 接口，不增加平行模型链路。产物预测仍使用单个反应物画板，单分子页面不变。
重复物料中的画板按可见区域延迟初始化，离屏且同步完成后释放 iframe，重新进入时恢复已同步的
结构；未完成编辑与错误仍保留，不丢弃输入。只读路线、检索结果和
文件多记录选择仍采用 RDKit 预览，不把每个结果装成编辑器。既有路线和化学验证门禁不变。

## 导航组织

桌面默认使用横排图标与中文标签，可收起为紧凑侧栏；窄屏仍使用可关闭、
支持焦点约束的导航抽屉。路线设计及反应输入工作台共用左侧参数、右侧结构画板的
表单布局，窄屏先展示化学输入，再展示参数与提交操作。绘图板在模式切换时保持挂载，
打开路线文档不销毁未提交的目标结构。视觉样式按设计变量、基础规则、导航壳和
内容表面分模块维护，只有一个公共样式入口，不增加另一套绘图或模型执行路径。

### 前端品质标准

设计目标是专业科学工作台的高品质，而非以动画、宣传页或自评代替真实可用性。
参考 [Awwwards 的设计、可用性、创造性与内容标准](https://www.awwwards.com/about-evaluation/)
和 [Webby 的导航、视觉、功能、交互与整体体验标准](https://www.webbyawards.com/judging-criteria/)，
获奖需由外部评审决定，不能通过单次构建或内部评分声明已达到。

共享设计规则位于 `apps/web/src/styles`：tokens 管理颜色、字体、尺寸与动效，foundation
管理基础排版、键盘焦点及减少动画，shell 管理导航与视口，surfaces 管理表单、表格与状态。
页面局部规则只负责自身布局，不建立第二套主题；技术详情、账号菜单和弹窗同样遵守这些规则。

| 验收对象 | 可检查的要求 |
|---|---|
| 导航与标题 | 一个主内容地标、键盘跳转、当前位置明确、标签清晰；小屏抽屉可退出并返回焦点 |
| 结构与反应输入 | Ketcher 为主、小尺寸 SMILES 辅助；加载/未确认/错误状态不可提交旧结构 |
| 历史与文档 | 长名称可读；主要打开操作优先，低频操作集中菜单；空/筛选/错误/加载状态不混淆 |
| 路线阅读与编辑 | 完整结构不裁切，目标/起始原料/中间体与正向步骤一致；编辑副本不冒充原计算 |
| 证据与采购 | 模型评分、相同反应、仅产物匹配、目录参考价与实验事实独立展示 |
| 表单与表格 | 单位与字段关联，状态不只用颜色；大表格在自身容器滚动，不撑破页面 |
| 主题与交互 | 共享颜色在浅/深色主题可读，焦点明确，悬停不改变尺寸，减少动画设置有效 |
| 性能与响应式 | 不引入远程字体/重型展示库；至少 390/768/1440/宽屏检查，真实图像就绪后才接受截图 |

绘图器的原生编辑与 SMILES 辅助字段保持同步，清空画板不能留下旧目标文字。
结构同步、文件选择或错误尚未处理时禁止提交；这与模型是否就绪分别展示，
输入问题不能被标为计算服务不可用。结构同步失败保留错误和提交门禁，但停止
无实际操作的进度动画。画布大小变化后重新适配当前结构，并通过原生视图事件
更新缩放文字；不改分子坐标、选择或撤销历史，不以化学修改事件刷新工具栏。

只读结构的复制入口支持键盘操作，并在实际写入成功后才显示“已复制”；权限拒绝或
写入失败保持明确反馈，不绕过浏览器权限。检索结果与模板详情复用只读结构放大窗口。
模板列表保留展开内容，返回时恢复原记录的焦点与阅读位置；索引总量、本次返回数量
和查询上限分别显示，不把有上限的结果列表声称为完整模板库。
参考反应确认预览暂时禁用执行与导出；取消且结构未改变时保留查询结果，
真正修改、应用新反应或切换查询仍使旧证据失效。

研究记录复用工作区的条件与产物结果组件，不显示可再次执行的历史验证按钮。
名称或编号等结构未确认的标签明确保留其身份边界。实验优化的历史表格与工作区
共享样式，CSV 导出使用已保存的原始内容，不重新生成预测或填充实测值。
实测行选择被容量门禁拒绝后，页首选择框必须回到真实选择状态；数据视图标签与
面板关联，支持键盘方向键切换，保持一个主内容地标。

验收同时检查默认、实际结果、空、加载、错误、菜单和弹窗。测试按改动和直接消费者选择，
不默认运行全仓测试。图形、文件与证据的正确性不能由截图、2xx 响应或构建成功单独证明。
浏览器自审需要保留真实页面截图和失败记录，修复后再捕获；不以模拟任务填充科学结果。

### 模块导航

侧栏提供路线设计、任务与路线两个工作入口，以及原料检索、反应与条件、结构工具、
工艺核算和实验优化；环境部署位于左下角。高频操作可直接到达，小功能按化学工作对象
合并，不把评分、绘图、库存或任务生命周期合并成同一种计算。

| 主入口 | 内部操作 | 保留边界 |
|---|---|---|
| 路线设计 | 完整路线、单步逆合成、打开路线文档 | 一步分析不再占第二个侧栏入口；所有模式继续使用同一绘图板与执行契约 |
| 任务与路线 | 路线任务、研究记录、保存的路线、编辑副本 | 原始计算与可编辑草稿独立存储；研究计算不冒充完整路线任务 |
| 原料检索 | 结构输入、精确查询、供应商目录 | 单功能工作区不叠加重复标签；采购快照不等于实时库存 |
| 反应与条件 | 条件推荐、产物预测、杂质候选、FF、模板检索 | NNv1、Graph2SMILES 与杂质分析使用产品同步边界；不存在旧异步模型备用链路；FF 是独立模型评分 |
| 结构工具 | SA/SPS/Bertz/描述符、SCScore、结构绘制 | 按真实结构计算，保留盐与同位素，不冒充实验可合成性证明 |
| 工艺核算 | 物料质量、分离产物、纯度、计量依据、PMI | 录入数据核算；缺项不补零，质量差额不是实测废物，不能替代放大验证 |
| 实验优化 | CSV、显式实测行、因子水平、响应、下一批条件 | BayBE / BoTorch；不读取未选响应训练，不给建议填实验收率 |
| 环境部署 | 引擎、部署配置、运行监测；已授权的用户/禁用规则管理 | 不提供浏览器执行系统命令；没有重复的本地工作区入口 |

每个研究工作区只显示自己的工具，不在原料查询上叠加反应/结构工具标签。反应与条件
直接切换其高频操作，结构工具直接切换评估、SCScore 与绘图。单功能工作区不叠加单项导航。
原生溶解度工作台保持一个二级入口。工具列表复用产品就绪快照；实验优化使用独立缓存探针，
不能阻塞路线搜索就绪，也不会因模型正在计算而撤掉已验证的入口。
点击当前工作区保留所选页面与结构/反应/模板预填，不把它重置到默认工具。
任务详情与路线编辑保持完整画布，不叠加集合页标签。
旧 `/results`、`/documents`、`/editor`、`/buyables`、`/feasibility`、`/molcom`、
`/template`、`/drawing` 等链接和节点分析预填保持有效，不引入重复路由或推理链路。
旧 `/forward?tab=impurity` 转入已接入的杂质工作区；未接入的选择性及非法模型标签转到
真实环境清单，不静默执行条件模型。未使用的旧杂质、区域和位点结果组件已移除，原生后端源码仍保留。

| DeepRetro | 旧 Conda 环境名不等同于软件集成 | 环境接入清单 |
| 商业目录 | 搜索与审查绑定同一不可变结构索引；不代表实时供货 | 精确 stock 查询与任务快照 |
| 模板知识索引 | 实际来源、方向、策略匹配数量分别报告 | template-library API |

环境展示源代码保留、配置、进程存在、模型就绪和产品 worker 就绪的差异。
原生能力 API 不再把上游部署清单冒充当前可用服务；原生异步模型队列未配置时拒绝
直接提交。路线仍通过产品统一任务入口执行，不引入第二个注册表或队列监督器。
环境接口只读，不提供网页系统命令。

## 点击链路

| 页面 | 点击路径 | 数据与状态约束 |
|---|---|---|
| 新建任务 | 绘图/结构文件 → 确认化合物 → 完整路线搜索/单步逆合成 | 显式提交才执行推理；已支持的重新搜索参数完整回放 |
| 任务历史 | 分组 → 全库名称/结构/状态筛选 → 卡片或列表 → 批量移组/归档/恢复 → 参数/预览 | 页与计数同一事务；标题与分组是独立历史元数据，不改变搜索输入或运行 revision；刷新及返回保留筛选 |
| 任务详情 | 完整路线列表 → 勾选路线 → 路线标签 → 图形/步骤/反应条件/物料清单 → 节点详情 | 预览弹窗和完整详情共用 RouteReader；排序与选择始终保持原路线索引，状态和路线文件独立加载 |
| 分子节点 | 节点 → 采购记录 → 完整原料检索/供应商目录 | 精确结构匹配；显示查询快照并比较原任务快照；不伪造 CAS、报价或包装 |
| 分子节点 | 节点 → 一步分析/结构复杂度 | 只预填所选结构，不自动推理，不修改原始路线 |
| 反应节点 | 节点 → 反应结构 → 可行性计算 | 反应物与产物来自实际图连接；模型响应失败不是无候选 |
| 反应节点 | 来源模板 → 模板详情 → 返回检索 | 来源与 ID 共同定位；训练序号与内部反应引用不能猜成模板 ID |
| 反应节点 | 实际反应 → 路线内条件弹窗/专利参考反应 → 研究记录或引用详情 | 打开弹窗不计算，显式预测才调用共用 NN 模型；关闭返回原路线与步骤；USPTO 原记录与 NN 预测分开 |
| 模板详情 | SMARTS/限制/参考记录 → 已明确的公开链接 | DOI、专利与 HTTP 链接校验；数字内部引用只显示原值 |
| 原料检索 | 预填/手输 → 验证 → 结构与记录一起提交显示 | 新查询失败或晚返回时不能将旧供应商记录挂在新结构上 |
| 路线文档 | 预览节点 → 编辑 → 应用 → 保存/导出 | 验证完成前固定节点与输入；切换节点后旧结果不能写入新节点 |
| 路线文档 | 未保存画布 → 打开路线文档 JSON | 用户确认前不创建导入文档、不清除修改、不跳转 |
| 路线文档 | 保存状态 → 科学状态 → 原始任务 | 保存成功与来源副本/草稿分开；修改化学结构使原计算声明失效 |
| 原生历史 | 历史记录 → 共享预览/详情 → 编辑副本 | 原生 UDS 用同一解码器投影；原文件保留，不重新认证商业闭合 |
| 环境部署 | 当前引擎 → 原生能力 → 未接入软件 → 数据依赖 | 只展示真实接入状态，未启用模块不是功能按钮 |
| 反应与条件 | 反应结构 → 参数 → 显式提交 → 候选 → 研究记录 | 输入变化使旧响应失效；两种模型评分不混作实验验证 |
| 杂质候选 | 反应物、已知主产物与试剂/溶剂 → 确认输入 → 五模式分析 → 结构与来源 → 研究记录 | 原子映射检查必须执行；已知产物是用户参照，不伪造其模型分数；不推断杂质含量 |
| 结构评估 | 化合物 → 计算 → 组分指标 → 方法来源 → 研究记录 | 完整结构身份与各组分分开；Na 等无机组分不造 SA 分数 |
| 工艺核算 | 产品/投料 → 质量单位/边界 → 计算 → 物料与 PMI → 研究记录 | 分离总质量、质量纯度和录入收率分别保留；不自动补全未知项 |
| 实验优化 | 真实 CSV → 选择记录 → 因子/响应 → 确认候选空间 → 推荐/导出 | 原始表 SHA256、所选行、条件空间和模型版本绑定；建议 CSV 的实测响应保持为空 |

研究记录由服务端在实际执行时写入 `analyses.sqlite`，不会接受浏览器伪造的预测作为模型结果。
成功、失败和中断分别记录；进程启动身份用于恢复判定，PID 复用不被当成仍在运行。
记录详情与原工作区共享结果组件。型号、原始输入与结果不可修改，不会在刷新时自动重新推理。

路线任务的分组、显示标题、回收箱和历史修订保存在原 `jobs.sqlite` schema 2，
不增加另一条任务链路。批量操作至多 100 条并校验逐项 owner 与 history_revision，任一失败全部回滚。
运行中任务可重命名和移组，不能归档。归档不删除原记录、事件或路线文件，恢复后保留真实科学状态；
解散分组仅把任务移回未分组。服务端搜索覆盖该用户的全部记录，页大小 24，
不以浏览器当前页过滤代替全库搜索。查询采用统一 1 秒执行预算；超时明确返回 503，
保留当前界面状态，不将未完成查询显示为无任务。

路线阅读共用完整分支缩略图、选中路线标签、图形、正向步骤、反应条件、物料清单和节点 inspector。
概览中的筛选与多选不占用详情画布；详情用路线标签、紧凑统计、独立图形/步骤/条件/物料工具栏，
结构图为主要信息。候选阅读使用固定大尺寸节点；版本 1 路线文档保留原紧凑节点尺寸与手动坐标，
不因主题升级自动重排已保存文件。每种模式的卡片显示、Dagre 排布与全图导出使用相同尺寸常量。
窄屏工具栏变为横排，筛选字段换行而不是压缩到无法辨认。完整 PNG 导出等待所有化学图片与
淡入动画完成，图片缺失、身份变化或等待超时会明确拒绝导出，不交付缺结构的图。
缩略图按可见区域延迟创建，滚动列表不会被图形缩放拦截。物料清单只列实际图的叶子化合物，
按完整结构身份去重，保留同位素、手性和盐组分；按需批量查询当前目录并对照任务快照，
不虚构需求量、实时报价或成本。可导出完整 PNG、物料 CSV 和版本 1 的 X-Synth 路线文档 JSON。
预览与编辑器共用文件契约；外部 JSON 导入为草稿，不继承商业闭合或模型审查结论。

参考反应 `/references` 共用产品 API，合并原生 Mongo `USPTO_FULL` 与独立 ORD 实验记录索引。
USPTO 保留原先的强制索引、3 秒数据库期限及 300 条召回边界；ORD 使用精确产物索引、
只读不可变 SQLite 和 4 秒查询期限。合并后最多 30 条结果，优先反应物/产物一致且含实际条件的记录。
每条记录仍按立体化学、同位素、电荷与组分核验。单个来源不可用不会伪装成无匹配，也不会阻塞
另一个真实来源；页面分别列出可用来源与查询失败来源。
专利号、段落、抽取收率、ORD 数据集/记录 ID、DOI/文献、源文件 SHA256 与数据许可保留出处。
ORD 产品测量保留分析方法、对应产品、原始字段、明确的百分比单位与零收率；不把计算字段改称分离收率。
温度/压力数值保留源精度，反应时间、加料时间点与加料时长分别标识；试剂、催化剂与溶剂只使用
原记录角色。实验文字原样展示，不把“过夜”、试剂名称或缺失量猜成确定的结构/参数。
仅产物一致的记录不能自动填写预测路线条件或收率，NN 预测仍属于独立模型结果。
这不是相似反应检索或实验验证，数据集也不是与训练输出序号兼容的新模板模型。
反应图使用后端核验后的完整结构数组，不直接将旧原子的映射编号/CX 扩展交给图示接口。
盐组分、立体化学、同位素和试剂均保留；原始反应字符串仍用于引用及复制，不改写来源。
参考记录可载入当前反应画板，但先由真实 RDKit RXN 导出/解析核对全部角色结构，再显示
确认预览。多个产物必须明确选择后续计算对象；选择只影响计算，不删除其它产物或试剂。
取消、换输入、换链接或离开页面均使未确认载入失效，迟到响应不能覆盖新画板。
载入不自动运行模型、启动路线搜索或把参考条件/收率写为编辑后反应的实验事实。
参考 RXN 导出使用各角色的独立结构数组，保留重复记录和多产物边界，不拼成一个混合物。
旧单产物调用仍支持 `product`；新调用使用 `products`，两者不能同时提交。结构数组来自
经过核验的完整 canonical SMILES；RXN 往返身份不一致时拒绝载入，不能静默改写结构。

采购目录参考价在原料检索、采购弹窗、物料清单与起始原料图节点之间共用价格契约。
`ppg` 显示为有出处的 `$/g` 目录基准，缺失的 ISO 币种、报价日期、包装与纯度保持未记录。
节点只显示与原任务库存快照一致的价格；读取当前其他快照必须另行查询并明确区分。
币种未确定时不自动比较跨供应商最低价，不相加得到所谓全路线成本，也不冒充供应商实时报价。

路线内条件预测复用独立工作台的 `useConditionPrediction` 与结果表，不另造模型执行链。
当前反应只读预览，明确选择候选数并点击预测；运行记录由实际产品 API 写入研究历史。
切换节点、关闭弹窗或离开页面后，迟到响应不能写入另一反应。预测不改原路线条件或实验事实，
NN 候选与原路线条件、专利记录仍为不同来源；没有后端资料时不复制商业软件的文献/成本字段。

预览与编辑共享 Vue Flow、Dagre、RDKit 与 Ketcher。节点分析共享同一 inspector；
采购弹窗与完整原料检索共享同一结构/快照响应校验。没有并存的旧 network 编辑器、
独立状态页或每结构专用推理脚本。
绘图写入队列以实际导入成功/失败事件为完成边界；提交前等待最新写入完成。
关闭页面会取消等待并释放监听器，超时或解析失败不得以输入文本替代画板结果。
取消或超时后不复用尚有后台写入的画板实例；重开弹窗创建独立实例。

## 验证与性能

只运行当前 diff 映射到的 Python/前端测试、构建和相关安全检查，不回退到全局套件。
模板导航契约测试使用真实 SQLite/FastAPI 响应与独立接口测试记录，公开 SMARTS 示例来自
[RDKit 文档](https://www.rdkit.org/docs/RDKit_Book.html#reaction-smarts)。测试中的计数、
ID 与分页参考记录仅是接口输入，不是预测结果、商业目录或实验文献。
它们不进入产品运行目录，也不替代本机真实模板库、库存和模型验收。CI 只在选择到这些测试时安装
产品 API 的哈希锁定依赖。`ci_scope` 传递所用 Python 解释器，
直接运行这些 npm 测试时可显式设置 `X_SYNTH_TEST_PYTHON`。

布局验收使用实际 Chrome/Playwright；API、库存、模板与所触及的模型执行路径需真实验证。
就绪缓存、模板摘要缓存与资源预算维持唯一权威，不通过降低科学门槛满足速度指标。
证据、截图、私人历史、模型与商业数据均保存在源码之外。
