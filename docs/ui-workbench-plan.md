# Synon ASKCOS UI Workbench Plan

The UI remains based on the migrated ASKCOS Vue UI.

## Required additions

| Area | Requirement |
|---|---|
| Task creation | Search strategy preset visible but ASKCOS parameters remain primary |
| Data-source status | Show ASKCOS, AiZynthFinder, buyables, ChemicalBook/domestic, ORD, Organic Syntheses status |
| Route history | Show running, completed, failed, unclosed, second-pass states |
| Route details | Show engine source, template source, evidence source, closure source |
| Route comparison | Show 3-10 final routes with route-family grouping |
| LLM review | Show LLM ranking only after hard gates pass |

## Design rules

- Chinese UI copy
- Apple-style clean workbench
- No broken icons
- No horizontal overflow
- No nested card clutter
- Real route data only
